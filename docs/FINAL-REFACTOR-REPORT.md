## 🎨 统一的设计语言

### 核心设计原则

1. **温暖优雅**
   - 柔和的配色
   - 舒适的间距
   - 人性化的圆角

2. **卡片优先**
   - 一切内容卡片化
   - 清晰的视觉层次
   - 统一的阴影系统

3. **渐变点缀**
   - 页面背景渐变
   - 图标徽章渐变
   - 装饰性渐变

4. **流畅动画**
   - Hover 提升
   - 缩放效果
   - 旋转动画

5. **响应式**
   - 移动端优先
   - 平板优化
   - 桌面充分利用空间

### 设计 Token

#### 圆角
- `rounded-lg` → 8px（小组件）
- `rounded-xl` → 12px（按钮/输入）
- `rounded-2xl` → 16px（卡片）
- `rounded-3xl` → 24px（大卡片）
- `rounded-full` → 圆形

#### 阴影
- `shadow-sm` → 轻阴影
- `shadow-lg` → 标准阴影
- `shadow-xl` → 强阴影
- `shadow-2xl` → 最强阴影
- `shadow-primary/20` → 彩色阴影

#### 间距
- `p-4` → 16px（紧凑）
- `p-6` → 24px（标准）
- `p-8` → 32px（宽松）
- `gap-4/6/8` → 一致的间距
