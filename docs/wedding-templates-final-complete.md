## 🎨 技术特点

### 1. 渐变背景
每个模板都使用了精心设计的多层渐变背景：
```json
"background": {
  "type": "color",
  "gradient": "linear-gradient(135deg, #color1 0%, #color2 50%, #color3 100%)"
}
```

### 2. SVG 装饰元素
所有装饰元素使用内联 SVG：
- ✅ 无外部请求，加载快速
- ✅ 可缩放矢量图形
- ✅ 体积小，性能好
- ✅ 支持透明度和颜色变化

### 3. CSS 动画
6 种动画类型：
- `fadeIn` - 淡入效果
- `slideUp` - 向上滑入
- `pulse` - 脉冲缩放
- `float` - 漂浮上下
- `swing` - 摇摆效果
- `shimmer` - 闪烁光泽

### 4. 完整的变量系统
每个模板包含 3 个可编辑变量：
- `couple_names` - 新人姓名
- `event_details` - 日期和地点
- `message` - 邀请词（支持 AI 生成）

### 5. 配色方案
每个模板提供 3 套配色方案，用户可以快速切换风格

## 🚀 使用方法

### 1. 导入数据库

```bash
# 方法 1: 使用 ts-node
npx ts-node scripts/import-wedding-templates.ts

# 方法 2: 编译后运行
npx tsc scripts/import-wedding-templates.ts
node scripts/import-wedding-templates.js
```

### 2. 在编辑器中使用

模板会自动出现在模板列表中，用户可以：
1. 选择任意模板
2. 编辑文字内容（新人姓名、日期、地点、邀请词）
3. 切换配色方案
4. 查看动画效果
5. 生成最终邀请函

### 3. 编辑器已升级支持

编辑器现在支持：
- ✅ 渐变背景渲染
- ✅ SVG 图层显示
- ✅ CSS 动画播放
- ✅ 变量替换
